# خطة العوالم

١٠ عوالم، ٧٠ مرحلة، ١٠ أسئلة للمرحلة. الخطة العامة موافَق عليها. تفاصيل مراحل كل عالم بتنعرض للموافقة قبل بنائه.

## العالم ١ (مبني)

٤ حروف بكل مرحلة بالترتيب الأبجدي. الأسئلة: ٤ «أين حرف» (حروف المرحلة)، ٣ «بأي حرف تبدأ الكلمة»، ٢ «أي صورة تبدأ بحرف»، ١ «أين حرف» مراجعة. الخيارات الغلط من حروف المرحلة والحروف المتقاربة السابقة.

## ناطر

- رأي المستخدم بالعالم ١ قبل ما نكمّل.
- فحص الصوت الآلي على موبايل حقيقي (ما انفحص).
- لاحقاً: تسجيلات المعلّمة، صور بدل الإيموجي، ربط منصة الجامع، رابط ثابت للنشر.
