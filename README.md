# رحلة الضاد

لعبة تعليم العربية لمدرسة دار الفرح (جامع فيرناو). ويب، عربي فقط، موبايل وتابلت.

## التشغيل

ملفات ثابتة بدون بناء. افتح `index.html` أو شغّل أي خادم ملفات:

```
python3 -m http.server 8000
```

## الموجود

- العالم ١ «حديقة الحروف»: ٧ مراحل، ١٠ أسئلة للمرحلة، ٤ حروف بكل مرحلة.
- ثلاثة أنواع أسئلة: أين الحرف، بأي حرف تبدأ الكلمة، أي صورة تبدأ بالحرف.
- باقي العوالم (٢–١٠) معروضة ومقفولة.
- نجوم، نقاط مدرسية (كل ٤ نجوم = نقطة)، ٦ شخصيات بتنفتح بالنجوم.
- التقدّم محفوظ على الجهاز (`localStorage`).

## الملفات

| الملف | شو فيه |
|---|---|
| `js/data/letters.js` | الحروف والكلمات والإيموجي |
| `js/data/worlds.js` | العوالم والمراحل والسرعات |
| `js/data/characters.js` | الشخصيات وعدد النجوم المطلوب |
| `js/data/audio-manifest.js` | تسجيلات المعلّمة |
| `js/game/questions.js` | توليد الأسئلة |
| `js/game/runner.js` | محرّك المسارات والبوابات |
| `js/game/draw.js` | رسم الشخصية |
| `js/ui.js` | الشاشات وإدارة الجولة |
| `js/storage.js` | حفظ التقدّم |

## استبدال الصوت الآلي

حط التسجيل في `assets/audio/` وأضف سطر في `js/data/audio-manifest.js`. المعرّفات مشروحة بنفس الملف. أي معرّف ما إله ملف بينقرأ آلياً.

## استبدال الإيموجي بصور

حط الصورة في `assets/img/words/` وأضف سطر في `DF.WORD_IMAGES` بملف `js/data/letters.js`:

```js
DF.WORD_IMAGES = { batta: 'assets/img/words/batta.png' };
```

## الربط مع منصة الجامع (لاحقاً)

النجوم الجديدة بتتسجّل في `state.events` داخل `js/storage.js` (مرحلة، عدد، وقت)، جاهزة للإرسال للمنصة.
